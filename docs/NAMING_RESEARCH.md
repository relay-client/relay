## Финалисты

- GitHub REST `/users/<name>`: HTTP 404 (публичный пользователь/организация не найдены).

- npm registry `/<name>`: HTTP 404, `Not found`.

- **Duplivo** — [расширение для счетов](https://duplivo.com/).
