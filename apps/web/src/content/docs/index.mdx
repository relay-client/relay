## Built for engineers who live in the terminal

<CardGrid stagger>
  <Card title="Local-first by default" icon="laptop">
    Your local profile and secrets are protected with AES-256-GCM. Git workspace YAML stays reviewable, with sensitive values replaced by local placeholders.
  </Card>
  <Card title="All the auth flows" icon="seti:lock">
    Bearer, Basic, Digest (RFC 2617), API Key, OAuth 2.0 (Client Credentials + Authorization Code with PKCE), AWS Signature v4. One-click token fetch where it makes sense.
  </Card>
  <Card title="Scriptable requests" icon="seti:javascript">
    Pre-request and test scripts in sandboxed JavaScript, with legacy Tengo support. Inject headers, assert responses, parse JSON, set variables.
  </Card>
  <Card title="Imports that travel" icon="random">
    Import Postman, Insomnia, Bruno/OpenCollection, OpenAPI, HAR, curl, or a full Relay backup. Export to Postman, OpenAPI, OpenCollection, or all-data backup.
  </Card>
  <Card title="Git-backed workspaces" icon="seti:git">
    Store workspaces as reviewable YAML, keep secrets local, and use diagnostics/conflict helpers when a repo changes underneath you.
  </Card>
  <Card title="Code generation" icon="seti:code-search">
    Copy any request as cURL, Python `requests`, JavaScript `fetch`, or Go `net/http`. More languages in the side panel.
  </Card>
  <Card title="Keyboard-first" icon="seti:config">
    Global search (⌘K), quick send (⌘↵), tab switching (⌘1–⌘9). All shortcuts configurable.
  </Card>
</CardGrid>

## Scripting that gets out of the way

<Code
  lang="js"
  title="pre-request + test"
  code={`// pre-request: inject a header
pm.request.headers.set("X-Client", "relay")

// test: assert status and parse JSON
pm.test("status is 200", () => pm.response.to.have.status(200))
const body = pm.response.json()
pm.test("has id", () => pm.expect(body).to.have.property("id"))`}
/>

Imports, `require`, process, filesystem, and network access are disabled. Execution caps at 2 seconds, so scripts can't escape the sandbox or block the UI.
