## Every release is on GitHub

Builds are published to
[relay-client/relay/releases](https://github.com/relay-client/relay/releases) — that page
is the download host, so there is no separate mirror to trust. `SHA256SUMS.txt` ships with
every release, and the in-app updater verifies both the checksum and a minisign signature
before it replaces anything.

## Older releases

Every published version stays on the releases page. If you need an older build, browse the
[full release list](https://github.com/relay-client/relay/releases) and pick a tag.

## Building from source

Clone [relay-client/relay](https://github.com/relay-client/relay) and follow the
[build instructions](https://github.com/relay-client/relay#building-from-source) — you need
Go, Node.js, and Wails v2.
