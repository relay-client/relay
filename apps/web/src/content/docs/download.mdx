## Verify your download

SHA256 checksums are published in `SHA256SUMS.txt`; auto-updates use the checksums and minisign signatures embedded in `latest.json`. Verify before running:

```sh
shasum -a 256 relay-*.dmg
# Should match the checksum on the release page.
```

## Older releases

Every published version stays on the releases page. If you need an older build, browse the [full release list](https://github.com/relay-client/relay/releases) and pick a tag.
