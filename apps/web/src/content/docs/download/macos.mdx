## Install

1. Open the `.dmg` and drag **Relay** into your **Applications** folder.
2. Launch it from Applications or Spotlight.

Current builds are not Apple-notarized, so the first launch is blocked by Gatekeeper. Open
**System Settings → Privacy & Security**, find the message about Relay, and choose
**Open Anyway**. You only have to do this once per installed version.

## Verify your download

Every release publishes `SHA256SUMS.txt`. Compare it against the file you downloaded before
you open it:

```sh
shasum -a 256 ~/Downloads/relay-*-darwin-universal.dmg
```

The value should match the line for that filename in `SHA256SUMS.txt` on the release page.

## Updates

Relay checks for updates itself and verifies the checksum and minisign signature of the new
build before replacing anything. You can turn the check off in **Settings → Updates**.
