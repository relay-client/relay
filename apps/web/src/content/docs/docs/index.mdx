## Conventions

- `Cmd/Ctrl` means Command on macOS and Ctrl on Windows and Linux.
- Commands prefixed `$` run in your terminal. Commands without a prefix run inside Kurlo, usually from the command palette (`Cmd/Ctrl K`).
- Screenshots use the light theme unless a guide says otherwise; the dark theme behaves identically.

## Need something the docs don't cover?

Open an issue or start a discussion on [GitHub](https://github.com/stormhop/kurlo/issues). Reports with steps to reproduce and the version from **Settings → About** get triaged fastest.
